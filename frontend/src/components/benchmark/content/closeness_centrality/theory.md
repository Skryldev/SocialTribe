# Theory

Closeness centrality measures how close a node is to all other nodes in the network. A node with high closeness centrality can reach many other nodes quickly through short paths, making it an efficient spreader of information.

## Key Concepts

- **Distance-based**: Based on shortest path lengths to all other nodes
- **Speed of propagation**: Measures how quickly information can spread
- **BFS-based**: Computed efficiently using Breadth-First Search
- **Centrality metric**: Identifies influential and well-connected nodes
- **Connected graph requirement**: Works best on fully connected networks

# Code of Conduct

## Our Commitment

We are committed to fostering an open, welcoming, respectful, and inclusive community. Participation in this project should be a positive experience for everyone, regardless of experience level, background, identity, nationality, or personal characteristics. We value constructive collaboration, respectful communication, and professional behavior.

## Our Standards

**Expected behavior:**

- Be respectful and courteous
- Provide constructive feedback
- Accept feedback gracefully
- Help others learn and improve
- Respect differing technical opinions
- Keep discussions focused on facts and technical reasoning
- Demonstrate empathy and professionalism
- Collaborate in good faith

**Unacceptable behavior:**

- Harassment or discrimination of any kind
- Personal attacks or insults
- Trolling or intentionally disruptive behavior
- Offensive, abusive, or hateful language
- Publishing private information without permission
- Threats or intimidation
- Deliberately misleading contributors
- Spam or promotional content unrelated to the project
- Repeatedly ignoring project guidelines after feedback

## Technical Discussions

Healthy technical disagreement is encouraged. When discussing architecture, implementation, or design decisions:

- Focus on technical arguments
- Support opinions with reasoning or evidence
- Respect alternative approaches
- Avoid turning technical disagreements into personal conflicts

Strong technical discussions are welcome. Disrespectful behavior is not.

## Maintainer Responsibilities

Project maintainers are responsible for:

- Promoting a respectful environment
- Reviewing contributions fairly
- Explaining decisions when practical
- Enforcing this Code of Conduct consistently
- Taking appropriate action when unacceptable behavior occurs

## Enforcement

Maintainers may take appropriate action in response to violations, including:

- Private warning
- Request to modify behavior
- Removal of inappropriate content
- Temporary restriction from participation
- Permanent ban for severe or repeated violations

Enforcement decisions are made in good faith with the goal of protecting the community.

## Reporting Issues

Report violations privately to the project maintainer. Include:

- Description of the incident
- Relevant links or screenshots (if available)
- Any additional context

Reports will be handled confidentially whenever possible.

## Scope

This Code of Conduct applies to all project spaces:

- GitHub Issues
- Pull Requests
- Discussions
- Documentation
- Community forums
- Project-related communication channels

It also applies when representing the project in public spaces.

## Attribution

## Thank You

Thank you for helping build a professional, respectful, and collaborative open-source community. Together, we create software that is not only technically excellent, but also enjoyable to build and maintain.
